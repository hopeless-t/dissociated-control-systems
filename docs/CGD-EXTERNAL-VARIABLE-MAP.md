# DCS-CGD external observation variable map

> Status: PUBLIC-SOURCE DESIGN MAP  
> Clinical authority: NONE

## Observation vector

The next external-facing DCS model should not collapse all reports into one
"cognitive score".

Define a visit-level observation vector:

~~~text
y(t) = [
  S(t),   # participant/self report
  I(t),   # informant/study-partner report
  O(t),   # objective standardized performance
  F(t),   # daily functional performance / assistance
  R(t)    # reporter / administration reliability covariates
]
~~~

### S(t) — self report

Examples from public ADNI schema:

- ECog participant report;
- Cognitive Change Index participant report where available.

Interpretation:

~~~text
S(t) = observation from the actor's self-model
S(t) != latent capability
~~~

### I(t) — informant report

Examples:

- ECog study-partner report;
- FAQ / CDR informant-derived information.

Interpretation:

~~~text
I(t) = external observer report
I(t) != objective truth
~~~

Informant characteristics can alter reporting. Public NACC literature therefore
motivates explicit reliability/context covariates rather than treating I(t) as
an oracle.

### O(t) — objective standardized performance

Candidate families available in public ADNI schema include:

- MoCA / MMSE;
- AVLT / Logical Memory;
- Trails;
- category fluency;
- other standardized cognitive tasks.

No single test is equated with global capability.

~~~text
O_j(t) = task-specific objective performance
~~~/

The modeling requirement is to retain task/domain identity rather than average
all tests into one latent score before checking whether that averaging is
justified.

### F(t) — daily function

Examples:

- Functional Assessment Questionnaire;
- instrumental activities represented in ECog domains.

This channel is needed because:

~~~text
Cognitive Test Performance != Everyday Functional Agency
~~~

### R(t) — reporter / measurement context

Candidate covariates include:

- informant relationship;
- cohabitation;
- participant/informant demographics when methodologically justified;
- administration source/mode;
- depressive symptoms when a study design requires adjustment;
- missingness and visit timing.

These variables are measurement-context controls, not latent disease labels.

## Derived discrepancy variables

Do not use absolute-value discrepancy as the only representation.
Direction matters.

~~~text
D_SI(t) = standardized I(t) - standardized S(t)
~~~

With impairment-oriented scales, positive D_SI can represent the informant
reporting more decline than the participant.

For an objective channel transformed to an impairment direction:

~~~text
D_SO_j(t) = standardized O_impairment_j(t) - standardized S(t)
D_IO_j(t) = standardized O_impairment_j(t) - standardized I(t)
~~~

The signs must be frozen per instrument before analysis.

## Longitudinal variables

The public literature supports treating awareness as dynamic rather than a
fixed trait.

Candidate quantities:

~~~text
Delta S   = S(t2) - S(t1)
Delta I   = I(t2) - I(t1)
Delta O   = O(t2) - O(t1)
Delta F   = F(t2) - F(t1)

Delta D_SI = D_SI(t2) - D_SI(t1)
~~~

A particularly important pattern to test is:

~~~text
objective/informant decline increases
while
self report remains comparatively stable
~~~

This pattern appears in published MCI awareness literature, but DCS must not
assume the cause is anosognosia without domain-local validation.

## Proposed latent decomposition

The smallest useful DCS decomposition for external observational modeling is:

~~~text
Z(t) = current task-relevant functional/cognitive state
A(t) = self-model calibration / awareness state
B(t) = external-reporter bias/context state
E(t) = environment / support / scaffold state
~~~

Observations are generated by combinations of these states.

A minimal linear thought model for identifiability analysis is:

~~~text
self report:      S = Z - A + eps_S
informant report: I = Z + B + eps_I
objective task:   O = Z     + eps_O
~~~

This is not a biological model. It is a structural-observation model used to
ask whether the available channels contain enough independent information.

## Track separation

### Track A — functional preservation / rerouting

Examples of evidence families:

- prospective-memory reminders;
- external memory aids;
- structured routines;
- task decomposition;
- environmental scaffolds.

Measured outcome should emphasize actual task completion and independence, not
only subjective confidence.

### Track B — root cause / disease modification

Examples:

- diagnosis and reversible contributors;
- disease biomarkers;
- progression models;
- disease-modifying or preventive interventions.

Invariant:

~~~text
Compensation != Disease Modification
~~~

## Current claim ceiling

This map is an observation architecture derived from public metadata and
published aggregate findings.

It does not establish:

- a clinical score;
- a diagnostic threshold;
- a treatment rule;
- a consent/capacity rule;
- an intervention-authority gate.
