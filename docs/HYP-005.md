# HYP-005 — Anticipatory Somatic Routing

> Status: OPEN HYPOTHESIS  
> Domain: human somatosensory / cognitive neuroscience  
> Biological interpretation: UNVALIDATED  
> Clinical authority: NONE  
> Treatment claim: NONE

## Question

Can attention, expectation, or near-body approach alter the state of a
body-part-specific somatosensory processing network **before** physical contact,
and thereby change the response to a later tactile input?

The working phrase **Anticipatory Somatic Routing (ASR)** names this
hypothesis. It is not a claim that attention creates peripheral touch signals,
nor that non-contact healing mechanisms have been established.

## Core hypothesis

Let:

~~~text
a_t  = spatial/body-part attention
e_t  = expectation of touch
p_t  = pre-contact proximity cues
u_t  = physical peripheral input
x_t  = partially observed somatic/control state
y_t  = measured response
~~~

The null model is:

~~~text
x_{t+1} = F(x_t, u_t) + noise
~~~

ASR adds endogenous and pre-contact terms:

~~~text
x_{t+1} = F(x_t)
        + B_a a_t
        + B_e e_t
        + B_p p_t
        + G(a_t, e_t, p_t) B_u u_t
        + noise
~~~

The key claim candidate is not merely that attention produces an additive
effect. It is that attention / expectation can alter the **gain or routing**
applied to a later peripheral input:

~~~text
G(a,e,p) != constant
~~~

A stronger interaction prediction is therefore:

~~~text
response(attention + touch)
!=
response(attention) + response(touch)
~~~

The direction of the interaction is not fixed in advance. Facilitation,
attenuation, or state-dependent sign changes are all admissible outcomes.

## Why this belongs in DCS

DCS asks whether a coarse global label hides distinct states of access,
integration, gating, and expression.

ASR adds a complementary question:

> Can an internal control variable configure a subsystem before the external
> signal that subsystem is expected to process has arrived?

This is a direct extension of:

~~~text
Capability != Accessibility
Global State != Uniform Subsystem State
Observable Behavior != Unique Internal State
~~~

into:

~~~text
Physical Input != Only Control Input
Pre-stimulus State != Neutral State
Attention != Peripheral Stimulation
~~~

## Evidence boundary

Existing human MEG work reports somatosensory alpha/beta modulation before an
expected tactile stimulus, including activity attributed partly to
contralateral primary somatosensory cortex. Tactile expectation and attention
can therefore alter measurable neural state before contact.

Expected-but-omitted tactile events can also evoke time-locked activity in
secondary somatosensory cortex and insula despite the absence of the expected
physical stimulus.

These observations support the plausibility of a **central preparatory /
predictive state**. They do not establish that:

- a peripheral afferent has fired without stimulation;
- attention is equivalent to touch;
- a specific healing effect follows from attention;
- a special biological field exists around a hand;
- Reiki, therapeutic touch, or other non-contact treatment claims are proven.

## Pre-contact decomposition

Observed response near a body should initially be decomposed as:

~~~text
R_observed =
    R_attention
  + R_expectation
  + R_visual
  + R_proximity_prediction
  + R_thermal
  + R_airflow
  + R_interaction
  + epsilon
~~~

A non-contact residual is therefore:

~~~text
R_residual =
    R_observed
  - R_known
~~~

where R_known includes the declared visual, thermal, airflow, attention, and
expectation controls.

A reproducible non-zero residual would be a reason to investigate an omitted
mechanism. It would not by itself identify that mechanism.

## Contact and pressure extension

Once contact occurs, physical input u_t becomes non-zero.

For mechanical stimulation, force alone is not a sufficient dose descriptor.
Candidate inputs include:

~~~text
u = (force, contact_area, force_rate, duration, velocity, frequency, site)
~~~

A minimal useful-vs-defensive model separates regulatory/affective response
from nociceptive/defensive response:

~~~text
U(u) = R_regulatory(u) - lambda * R_defensive(u)
~~~

This permits an empirical sequence such as:

~~~text
sub-threshold
  -> effective window
  -> local optimum
  -> nociceptive knee
  -> defensive-dominant regime
~~~

The stronger claim

~~~text
pain onset => beneficial pathway = 0
~~~

is **not** assumed.

The preferred DCS hypothesis is a **control-dominance switch**: defensive
processing may become dominant while other pathways remain active.

## Competing hypotheses

### H0 — No anticipatory somatic routing

After accounting for ordinary baseline variation:

~~~text
B_a = B_e = B_p = 0
G(a,e,p) = constant
~~~

Attention and expectation do not materially alter the relevant somatic state.

### H1 — Additive central preparation

Attention / expectation shift neural state but do not change the transfer
function applied to later touch:

~~~text
B_a or B_e != 0
G(a,e,p) = constant
~~~

### H2 — Gain / routing modulation

Attention / expectation change the response to later physical input:

~~~text
G(a,e,p) != constant
~~~

### H3 — Proximity effect explained by known channels

Any pre-contact effect is explained by some combination of visual approach,
thermal radiation, airflow, timing, expectation, and multisensory prediction.

### H4 — Residual pre-contact effect

A repeatable effect remains after declared known channels are controlled.

H4 is an **open residual hypothesis**, not a claim that an unknown field or
healing mechanism exists.

### H5 — Nociceptive control-dominance switch

As mechanical dose increases, the net response crosses a reproducible region
where defensive/nociceptive processing begins to dominate regulatory or
pleasant response.

## Falsifiable predictions

### P1 — Body-part specificity

Directing attention to body part A should alter at least one predeclared
neural/behavioral measure more for A than for a matched unattended body part B.

### P2 — Pre-stimulus timing

The effect must begin before the physical tactile input. A post-stimulus-only
difference is insufficient evidence for ASR.

### P3 — Interaction

At least one response to identical physical input should differ between
attended and unattended conditions after baseline correction.

### P4 — Omission response

If a timed tactile event is strongly expected and then omitted, a repeatable
time-locked central response may still occur. This tests prediction, not
peripheral stimulation.

### P5 — Distance / approach decomposition

Any apparent near-body transition should be re-tested while independently
controlling visual approach, expectation, thermal cues, and airflow.

### P6 — Pressure knee

If a beneficial/pleasant response window exists, increasing declared mechanical
dose should eventually produce a change in slope, state occupancy, or coupling
consistent with a defensive-dominant regime.

## Candidate experiment matrix

The first experiments should remain non-clinical and low-risk.

~~~text
A  neutral baseline
B  attention to target body part; no touch
C  expected touch; omitted
D  identical touch; attention elsewhere
E  identical touch; attention to target
F  visible near-approach; no contact
G  matched near-approach with visual cue removed
H  thermal / airflow matched non-human control
~~~

Primary comparison candidates:

~~~text
B - A                     endogenous attention effect
C - B                     expectation / omission effect
E - D                     gain / routing interaction
F - A                     total pre-contact effect
F - G                     visual-approach contribution
F - H                     human-hand-specific residual candidate
~~~

Any human-hand residual requires replication and progressively stronger
controls before mechanism claims.

## Observable families

Possible observables include:

- reaction time / tactile detection threshold;
- evoked and induced EEG/MEG measures;
- source-localized alpha/beta/gamma changes;
- autonomic observables such as heart-rate dynamics or electrodermal activity;
- subjective pleasantness, pain, expectancy, and body-location reports.

No single observable is a privileged ground-truth measure of the latent state.

## Model-identification target

A useful model should estimate more than a condition mean.

The stronger target is:

~~~text
p(x_{t+1} | x_t, a_t, e_t, p_t, u_t)
p(y_t | x_t)
~~~

and compare candidate models by out-of-sample prediction.

The scientific milestone is:

~~~text
predict before observe
~~~

not merely fitting a flexible model after observing the result.

## Relation to HYP-004

HYP-004 asks whether a bounded local intervention can move the whole system
between qualitatively different observable regimes.

HYP-005 supplies a candidate class of interventions that includes **internal
control inputs**:

~~~text
attention / expectation
  -> local somatic preparation
  -> altered access / gain
  -> changed response to identical peripheral input
~~~

If supported, this would show that intervention in DCS need not be only an
external physical perturbation.

## Safety and scope

This hypothesis does not authorize self-experimentation involving painful
stimulation, electrical stimulation, drugs, injury, or deliberate induction of
altered consciousness.

Electrical stimulation, invasive recording, painful thresholds, or clinical
intervention require separate safety, ethics, and domain-specific protocols.
