# HYP-007 — Human Control-Space Reshaping

> Status: OPEN HYPOTHESIS  
> Domain: motor control / skill acquisition / human performance  
> Clinical authority: NONE  
> Training prescription authority: NONE

## Question

Does expertise primarily reflect a scalar increase in capability, or can it be
better explained as a structured reshaping of the control space available to a
person?

The working hypothesis is:

~~~text
Expertise != one scalar capability increase
~~~

Instead, training may change:

~~~text
controllability
observability
sensory weighting
prediction
reachable state / action set
variability structure
policy complexity
feedback dependence
transferability
~~~

## Two-timescale formulation

Fast movement dynamics:

~~~text
x_{t+1} = f(x_t, u_t, d_t ; Theta_n)
y_t     = h(x_t)
xhat_t  = E_Theta(y_0:t, u_0:t-1)
u_t     = pi_Theta(xhat_t, goal_t, context_t)
~~~

Slow controller adaptation:

~~~text
Theta_{n+1}
=
T(
    Theta_n,
    practice_n,
    error_n,
    reward_n,
    feedback_n
)
~~~

The research target is the update operator T.

## Controller state

A candidate state is:

~~~text
Theta = {
    capability_ceiling,
    accessible_control_basis,
    observability,
    sensory_weights,
    internal_model,
    policy,
    controllable_state_set,
    variability_structure,
    retained_memory
}
~~~

Visible performance is only a projection of Theta.

## Key DCS distinctions

HYP-007 adds:

~~~text
Capability
!=
Accessibility
!=
Controllability
!=
Observability
!=
Task Utility
~~~

A physical capability may exist while:

- the person cannot voluntarily access it;
- the person cannot observe it reliably;
- the capability is accessible but not useful for the target task;
- the visible output is achieved through compensation rather than genuine
  expansion of the target subsystem.

## Central prediction

If the hypothesis is useful, expert and novice differences should be better
predicted by named control-transition variables than by one global skill label.

For example, two people can produce the same visible output while differing in:

~~~text
control effort
feedback dependence
compensation
sensory weighting
available solution set
task-relevant variance
anticipatory timing
~~~

## Variability prediction

For output z = g(x), linearize with:

~~~text
J = dg/dx
~~~

and decompose:

~~~text
delta_x = delta_x_null + delta_x_task
~~~

where:

~~~text
J delta_x_null = 0
J delta_x_task != 0
~~~

HYP-007 predicts that expertise may reduce task-harmful variability without
eliminating all internal variability.

Therefore:

~~~text
lower total variance
!=
universal definition of expertise
~~~

## Transition qualification

For one declared ability k:

~~~text
U0  UNMAPPED
O1  OBSERVABLE
A2  ACCESSIBLE
I3  INDIVIDUATED
C4  CALIBRATED
R5  ROBUST
T6  TRANSFERABLE
M7  AUTOMATIZED
~~~

This is a research coding scheme, not a biological developmental law.

## General-adult prediction

HYP-007 does not require elite genetics or elite training loads to be testable.

Some transitions should be measurable in ordinary adults using bounded,
nonclinical tasks.

The strong transfer claim is not:

~~~text
practice skill X -> become globally better
~~~

but:

~~~text
a declared control property can change
and the change can be measured independently from task score
~~~

Transfer must be tested explicitly.

## Falsification criteria

HYP-007 weakens if:

1. named transition metrics do not explain held-out performance better than a
   scalar expertise label;
2. apparent control-space expansion is consistently explained by compensation;
3. control changes do not survive feedback removal or representative
   perturbation;
4. training effects remain completely task-local with no predicted transition
   signature;
5. transition labels cannot be operationalized reliably across laboratories;
6. the ontology adds terminology without reducing ambiguity or improving
   prediction.

## Evidence boundary

Current literature supports domain-local examples of:

- short-term finger individuation changes;
- anticipatory postural adjustment in archery;
- sensory reweighting differences in gymnastics;
- functional variability and affordance use in climbing;
- compensated movement as a distinct issue in ballet;
- smoothness / jerk differences in surgical skill.

This does not establish one universal mechanism of expertise.

Named elite performers are hypothesis generators unless their proposed
transition was directly measured.

## Safety boundary

The hypothesis does not authorize extreme range-of-motion training, forced
joint positions, painful threshold seeking, risky balance tasks, high-load
novel exercises, or unsupervised clinical rehabilitation.

The general-person research lane should use low-risk tasks and separate
performance improvement from transfer, retention, and compensation.

## Deepening: update-class identifiability

HYP-007 now distinguishes the visible transition label from the underlying
controller component that actually changed.

Candidate atomic update classes:

~~~text
U-PHYS    physical / morphological capability
U-BASIS   accessible control basis / synergy
U-OBS     observability
U-WEIGHT  sensory weighting
U-MODEL   predictive / internal model
U-POLICY  control policy
U-REACH   controllable / reachable state set
U-VAR     variability structure
U-MEM     retention / retrieval state
~~~

A measured performance gain does not identify one of these classes by itself.

Therefore:

~~~text
task improvement
!=
mechanism identification
~~~

HYP-007 requires perturbation fingerprints such as sensory perturbation,
mechanical perturbation, feedback removal, context shift, component constraint,
or dual-task load where appropriate.

## Deepening: transition grammar

The ontology is not assumed to be an unordered bag of labels.

Some transitions may form productive compositions:

~~~text
DISCOVER
 -> ACCESS
 -> INDIVIDUATE
 -> CALIBRATE
 -> REINTEGRATE
 -> ROBUSTIFY
 -> INTERNALIZE-FB
 -> TRANSFER
 -> AUTOMATIZE
~~~

This sequence is a hypothesis, not a universal curriculum.

A second important path is:

~~~text
AUGMENT-OBS
 -> CALIBRATE
 -> INTERNALIZE-FB
~~~

with a failure branch:

~~~text
AUGMENT-OBS
 -> FEEDBACK-DEPENDENT
~~~

The order of transitions may matter:

~~~text
T_A(T_B(Theta))
!=
T_B(T_A(Theta))
~~~

This non-commutativity is an explicit future research question.

## Deepening: timescale and hysteresis

The same visible state can arise through different histories.

HYP-007 therefore allows:

~~~text
within-movement correction
trial-to-trial adaptation
session learning
retention / consolidation
long-term restructuring
physical adaptation
~~~

to coexist on separate timescales.

The state transition may depend on history:

~~~text
P(q_{n+1} |
    q_n,
    practice_n,
    history_0:n,
    context_n)
~~~

rather than only the immediately previous state.

This permits retention, washout, reacquisition, and spontaneous-recovery
questions.

## Deepening: representative robustness

The hypothesis does not equate practice variability with robustness.

Define:

~~~text
P_train(d)
P_target(d)
~~~

as the perturbation distributions in training and target use.

A ROBUSTIFY claim should declare how representative the training distribution
is of the target distribution.

~~~text
random variation
!=
representative variation
~~~

Retention and transfer must be measured separately from acquisition.

## Deepening: feedback internalization

Augmented observation is useful only if the claim matches what remains after
the added channel is removed.

Define:

~~~text
Dependency =
    performance_with_feedback
  - performance_without_feedback
~~~

A successful INTERNALIZE-FB transition predicts that this dependency decreases
after learning.

## Deepening: cross-domain transition signature

Each experiment should report a transition signature rather than only a task
score:

~~~text
Delta = [
    task_change,
    transfer_change,
    retention_change,
    observability_change,
    controllability_change,
    task_harmful_variance_change,
    cost_change,
    feedback_dependency_change,
    risk_or_compensation_change
]
~~~

## Dependency-aware motor-control extension

HYP-007 now distinguishes a single-effector mental model from a distributed
coordination model.

For a task-level control vector z and muscle / actuator activation m:

~~~text
m = S z
~~~

where S is a task-dependent coordination / synergy map.

The consciously perceived linkage model may be:

~~~text
Shat
~~~

with:

~~~text
Shat != S
~~~

A candidate learning sequence is:

~~~text
HIDDEN-LINKAGE
 -> LINKAGE-DISCOVER
 -> SYNERGY-AWARE
 -> ATTENTIONAL-REPARAMETERIZE
 -> LOAD-ROUTE
 -> REINTEGRATE
~~~

The hypothesis is not that conscious attention directly specifies every muscle
activation.

The narrower claim is that attention may alter the represented control
coordinates or the selection among available whole-body solutions.

A high-dimensional body state:

~~~text
q in R^n
~~~

may be controlled through a lower-dimensional conscious representation:

~~~text
z in R^k
k << n
~~~

with:

~~~text
q = Phi(z, context, fatigue, task)
~~~

Candidate z variables include axis, orientation, linkage, task direction, and
load-distribution cues.

This extension is cross-linked to [HYP-008.md](HYP-008.md), where the same
formal problem is represented as dependency-aware distributed control.
