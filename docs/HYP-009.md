# HYP-009 — Meta-Adaptive Closed-Loop Optimization

> Status: OPEN HYPOTHESIS  
> Scope: formal control / synthetic validation  
> Biological interpretation: UNVALIDATED  
> Production authority: NONE

## Question

Can a closed self-improvement loop improve not only the controlled object, but also
its own sensing, candidate-generation, escalation, rollback, and stopping policy?

The hypothesis is deliberately broader than one drawing task.

The shared formal object is:

~~~text
state estimate
  -> prediction
  -> bounded action
  -> observation
  -> prediction error
  -> calibration
  -> policy update
  -> next trajectory
~~~

The meta-loop adds:

~~~text
loop telemetry
  -> loop critic
  -> loop-policy update
  -> changed sensing / action / stopping strategy
~~~

## Core distinctions

~~~text
Improvement != Loop Improvement
More Iterations != More Learning
More Observation != More Information
Faster Execution != Higher Learning Velocity
Action Policy != Observation Policy
Local Performance != Transferable Skill
Critic Result != External Authority
~~~

The final invariant matters especially for AI/agent transfer: learning may update a
research policy, but it must not self-grant production or execution authority.

## State decomposition

Let the object-level controller have latent state `x_t`, action `a_t`, and
observation `y_t`.

Let the loop itself have a meta-state:

~~~text
m_t = [
    observation policy,
    candidate policy,
    critic policy,
    escalation policy,
    rollback policy,
    stopping policy,
    cache / memory state
]
~~~

Then:

~~~text
x_(t+1) = f_theta(x_t, a_t)
y_(t+1) = h_theta(x_(t+1)) + epsilon

m_(t+1) = g_phi(
    m_t,
    loop telemetry,
    prediction residual,
    accepted / rejected outcomes
)
~~~

This separates object adaptation from loop adaptation.

## HYP-009-A — Active observation

The loop can reduce expected sensing cost by choosing the cheapest observation that
is expected to resolve the current decision.

For hypothesis state `H` and observation action

~~~text
o = (critic subset, semantic region, precision)
~~~

define:

~~~text
o* = argmax_o I(H ; Y_o | history) / C_obs(o)
~~~

### Falsifier

If an active observation policy has equal or greater decision error and equal or
greater total sensing cost than a fixed observation policy on held-out tasks, the
hypothesis is not supported for that regime.

## HYP-009-B — Learning velocity

Raw iteration count is not the target quantity.

Define:

~~~text
learning_velocity =
    useful_learning_gain
    -----------------------------------------------
    render_cost + observation_cost + decision_cost
~~~

A faster loop is useful only if it preserves declared hard criteria and produces
equal or better retained learning per total cost.

### Falsifier

If a lower-cost loop increases rollback distance, false promotion, or held-out
performance loss enough to erase its cost advantage, it is not a superior loop.

## HYP-009-C — Effective pressure

The number of simultaneous critic dimensions is an incomplete pressure measure.

Proposed proxy:

~~~text
P_eff =
    alpha * |S|
  + beta  * sum(negative interaction strength)
  + gamma * sum(intervention magnitude^2)
  + eta   * execution cost
~~~

Two updates with the same critic count may have very different pressure because
their interaction topology and intervention magnitude differ.

### Falsifier

If raw issue count predicts regression/cost as well as or better than the richer
pressure proxy on held-out episodes, the extra model complexity is unnecessary.

## HYP-009-D — Rare failures as high-information events

A low-frequency regression may carry more model-identification value than a routine
success if it separates competing latent explanations.

Failure-state biopsy should capture at minimum:

- pre/post latent-state estimate;
- active critic subset;
- observation policy;
- changed semantic targets;
- intervention magnitude;
- prediction residual;
- rollback source;
- accepted / rejected decision.

The goal is not to maximize failures. It is to avoid wasting informative failures.

## Sequential observation known-answer example

For a three-stage cascade:

~~~text
c0 = 13,491
c1 = 33,244
c2 = 78,875

p0 = 0.5
p1 = 0.5
~~~

where `p0` is the conditional stop probability after stage 0 and `p1` after
stage 1:

~~~text
E[C]
  = c0
  + (1-p0)c1
  + (1-p0)(1-p1)c2

  = 49,831.75
~~~

This is lower than unconditional use of the final stage:

~~~text
49,831.75 < 78,875
~~~

The numbers are a deterministic known-answer fixture, not a universal sensor law.

## Relation to HYP-007 and HYP-008

HYP-007 studies control-space reshaping and distinguishes adaptation, retention,
transfer, feedback dependence, and non-commutative updates.

HYP-009 asks a complementary question:

> Can the training / observation / correction loop itself become a learned
> controller?

HYP-008 separates dependency, authority, observation, information, and load graphs.
That separation is preserved here. In particular:

~~~text
Observation optimization != Authority optimization
Learning policy != Execution grant
Fast loop != Permission to bypass evidence or review
~~~

## Transfer boundary

A correspondence among human motor learning, drawing practice, AI-agent feedback,
and software control loops may be useful at the level of state estimation,
prediction error, feedback, and policy adaptation.

It does not establish a shared physical mechanism.

~~~text
Shared closed-loop equation != shared biology
Synthetic speedup != human learning proof
Drawing-loop success != production-agent safety
~~~

## Planned validation

1. deterministic known-answer tests for observation cascade cost;
2. active-sensing policy against fixed-resolution baselines;
3. effective-pressure model against raw issue count;
4. static loop policy vs meta-adaptive loop policy;
5. held-out transfer to a new task family;
6. rare-event biopsy and replay;
7. ablation of memory / cache / rollback components.

## Claim ceiling

A successful synthetic validation may establish only:

~~~text
META_LOOP_PRIMITIVES_DEFINED
ACTIVE_OBSERVATION_KNOWN_ANSWER_VALIDATED
EFFECTIVE_PRESSURE_PROXY_IMPLEMENTED
~~~

It cannot establish a human-learning mechanism, biological equivalence, or
production authority.
