# VAL-001 — Latent-State Non-Identifiability

## Purpose

Validate the smallest formal claim required by this repository:

> A coarse observation can be compatible with more than one internal subsystem
> state.

VAL-001 is a synthetic known-answer validation, not a neuroscience experiment.

## Frozen state vector

~~~text
[motor, procedural, executive, memory]
~~~

Each bootstrap value is binary.

## Frozen coarse observation

~~~text
complex_action =
    motor == 1
    AND
    procedural == 1
~~~

Executive and memory dimensions are hidden from the coarse observer.

## Known-answer states

Integrated reference:

~~~text
[1,1,1,1]
complex_action = true
D = 0
~~~

Dissociated reference:

~~~text
[1,1,0,0]
complex_action = true
D = 1
~~~

The coarse observation is identical; the latent state is not.

## Equivalence-class known answer

There are 16 binary four-dimensional states.

Exactly four satisfy complex_action=true because motor and procedural are fixed
ON while executive and memory are free.

~~~text
N(complex_action=true) = 4
~~~

## Acceptance checks

VAL-001 PASS requires all of:

1. integrated and dissociated states are unequal;
2. both emit the same coarse complex_action observation;
3. richer observations differ;
4. integrated D equals 0;
5. dissociated reference D equals 1;
6. every binary state has D in [0,1];
7. complex_action=true equivalence class size equals 4;
8. invalid state values fail closed.

## Claim ceiling

PASS means only that the bootstrap model and harness correctly represent a
deliberately constructed partial-observability ambiguity.

PASS does not establish a biological mechanism.
