# HYP-010 — Skill Compilation and Cheap Replay

> Status: OPEN HYPOTHESIS
> Scope: synthetic control / meta-learning formalism
> Biological interpretation: UNVALIDATED
> Production authority: NONE

## Question

Can a repeatedly successful closed-loop trajectory be compiled into a bounded
reusable policy so that later tasks can skip most of the original search cost?

## Skill capsule

A compiled skill contains:

- applicability preconditions;
- bounded action macro;
- observation / verification macro;
- hard guards;
- rollback / partial-merge rule;
- confidence region;
- provenance;
- cost model.

## Cost model

Discovery:

C_discovery = sum(search + execution + observation + decision)

Replay:

C_replay = C_match + C_macro + C_verify

Compilation is useful when the amortized replay cost is lower than repeated
rediscovery cost.

## Decompilation rule

Compiled does not mean frozen.

If a task leaves the calibrated confidence region, a guard fails, or replay
residuals grow, the controller must reopen the skill into exploratory steps.

## Core distinctions

Skill != universal rule
Replay != proof of transfer
Compression != lossless generalization
High confidence != external authority

## Planned tests

1. deterministic applicability checks;
2. known-answer replay-savings calculations;
3. held-out task replay vs fresh rediscovery;
4. transfer-failure injection;
5. skill decompilation after confidence-region violation;
6. skill composition under conflicting guards.
