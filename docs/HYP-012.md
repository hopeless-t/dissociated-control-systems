# HYP-012 — Information-Gain Curriculum Selection

> Status: OPEN HYPOTHESIS
> Scope: synthetic control / meta-meta learning formalism
> Biological interpretation: UNVALIDATED
> Production authority: NONE

## Question

Can a self-improving system accelerate skill acquisition by choosing the **next
practice task** according to expected information gain and gap coverage rather than
repeating familiar tasks?

The hypothesis is that curriculum selection is itself a control problem.

## Candidate task score

For candidate task t:

~~~text
Q(t) =
    E[information_gain(t)]
  + alpha * gap_coverage(t)
  + beta  * transfer_value(t)
  - gamma * redundancy(t)
  --------------------------------
  execution + observation + integration cost
~~~

The best next task is the one with the highest expected useful learning per cost,
not the task with the lowest raw execution cost.

## Expected behavior

Prefer a novel task when it:
- covers a known capability gap;
- is likely to falsify or refine the world model;
- has high transfer value;
- is not redundant with recently solved tasks.

Prefer repetition when it:
- is required to establish stability;
- has high expected information about a still-uncertain skill boundary;
- is needed for held-out replay validation.

## Falsifiers

This hypothesis is not supported if:
1. information-gain scheduling does not improve held-out skill/transfer per total cost;
2. a fixed or random curriculum performs equally well or better;
3. novelty seeking increases failure cost without improving calibration/transfer;
4. redundancy penalties prevent necessary repetition and reduce reliability.

## Claim ceiling

Synthetic success may establish only:

~~~text
CURRICULUM_SCORING_PRIMITIVES_DEFINED
GAP_AWARE_TASK_SELECTION_IMPLEMENTED
DETERMINISTIC_TASK_SELECTION_TESTED
~~~

It does not establish a human learning law or autonomous production authority.
